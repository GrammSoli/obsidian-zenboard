# Инструкции

1. Установите плагины Dataview, Calendar, Periodic Notes, Templater, Homepage и при желании Iconize.
2. В Calendar и Periodic Notes задайте шаблоны имен:
   - День: `YYYY-MM-DD`
   - Неделя: `YYYY-WWW`
   - Месяц: `YYYY-MM`
   - Год: `YYYY`
3. В настройках Templater укажите папку шаблонов `99_Z-Archive/Templates` и включите триггер при открытии для обновления поля `обновлено`.
4. В плагине Homepage выберите стартовую страницу `00_Dashboard/Dashboard`.
5. Файл `00_Dashboard/_dashboard.css` поместите в `.obsidian/snippets` и включите его в разделе Appearance → CSS Snippets.
